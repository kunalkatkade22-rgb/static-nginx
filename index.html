Labs

Do them in order. Each one adds one idea to the last.

Run a container

Start nginx in the background and open it in the browser.

docker run -d -p 80:80 nginx

Write a Dockerfile

Copy this page into an nginx image so it ships with its own server.

docker build -t myweb .

Map ports

Run the same image on two host ports and see both respond.

docker run -d -p 8080:80 myweb

Use a volume

Mount a local folder, edit index.html, refresh, and see the change.

docker run -v $(pwd):/usr/share/nginx/html:ro

Docker Compose

Describe the container in a YAML file and start it with one command.

docker compose up -d

Push to a registry

Tag the image with your username and push it to Docker Hub.

docker push user/myweb:1.0

    Run this page in Docker

    Put index.html, Dockerfile and .dockerignore in one folder on your server, then:

    1. Build the image 
      docker build -t myweb:1.0 .
    2. Start a container 
      docker run -d --name myweb -p 80:80 myweb:1.0
    3. Open http://<your-server-ip> in a browser. Port 80 must be open in the security group.
    4. Stop and remove it when you finish 
      docker stop myweb && docker rm myweb
    Served by nginx in a container. Edit index.html, rebuild, and run again.
